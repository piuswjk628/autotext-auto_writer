# 문서 자동 입력 — C# / Visual Studio

Python 없이 동작하는 Windows Forms 프로그램입니다.

## 실행

`bin/publish/AutoInput.exe`를 실행합니다. TXT/DOCX를 선택하고 F8을 누른 뒤 대기 시간 안에 입력할 창을 클릭하세요. F9 또는 Esc로 중지합니다. 중지 후 재시작하면 처음부터 입력합니다. 글자 간격의 단위는 ms입니다.

키보드 유니코드 이벤트를 사용하며 클립보드는 사용하지 않습니다. 줄바꿈은 Enter, 탭은 Tab 키이므로 채팅 메시지 전송이나 입력 칸 이동이 발생할 수 있습니다. 메모장에서 먼저 확인하세요. 대상 앱이 관리자 권한으로 실행되거나 유니코드 입력을 지원하지 않으면 입력되지 않을 수 있습니다. DOCX는 본문과 표의 텍스트를 읽으며 서식, 그림, 머리글은 포함하지 않습니다.

## Visual Studio에서 빌드 및 배포

1. .NET 10을 지원하는 Visual Studio에 `.NET 데스크톱 개발` 워크로드를 설치합니다.
2. `AutoInput.sln`을 엽니다.
3. Release 구성으로 빌드합니다. F5로 프로그램을 실행할 수 있습니다.
4. 프로젝트를 오른쪽 클릭 → 게시 → `Windows` 프로필 → 게시를 누릅니다.
5. `bin/publish/AutoInput.exe`를 배포합니다. Windows x64용이며 .NET 실행 환경이 포함됩니다.

명령으로 배포할 수도 있습니다.

```powershell
dotnet publish AutoInput.csproj -p:PublishProfile=Windows
```

단축키를 다른 프로그램이 사용 중이면 화면의 버튼을 사용하세요. Esc는 입력 작업 중에만 전역 단축키로 등록됩니다. 완료 표시는 키보드 이벤트 전송 완료를 뜻하며 대상 앱의 저장 성공까지 확인하지 않습니다.

## 일시정지 / 이어 입력

F10 또는 일시정지 버튼으로 멈추고, 다시 F10 또는 이어 입력 버튼을 누르면 같은 위치에서 계속 입력합니다. 재개 시 설정된 시작 대기 시간만큼 기다리므로 대상 입력창으로 돌아가세요. 일시정지 중에도 F9 또는 Esc로 완전히 중지할 수 있습니다. 완전 중지 후 F8을 누르면 처음부터 시작합니다.

## 도움말과 설정

창 좌측 상단의 도움말에서 사용 방법과 단축키를 확인할 수 있습니다. 도움말을 열면 실행 중인 입력이 일시정지됩니다.

설정 메뉴:
- 다크 모드: 어두운 배경과 밝은 글자
- 자동 줄바꿈: 미리보기 표시만 변경하며 실제 입력 내용에는 줄바꿈을 추가하지 않음
- 항상 위에 표시
- 입력 시작 시 창 최소화
- 글자 크기: 미리보기 10~22pt
- 기본 설정으로 복원

시작 대기 시간과 글자 간격도 자동 저장됩니다. 설정은 사용자별 `%LOCALAPPDATA%/AutoInput/settings.json`에 저장합니다. 읽기나 저장에 실패하면 화면 상태에 안내하며 현재 실행은 계속 사용할 수 있습니다.

## 예상 완료 시간과 시작 대기

본문 아래에 예상 완료 시각과 남은 시간을 표시합니다. 문서 길이, 글자 간격, 시작 대기 시간으로 계산하는 근사치이며 대상 프로그램과 컴퓨터 속도에 따라 달라질 수 있습니다. 일시정지 중에는 완료 시각 대신 남은 입력 시간을 표시하고 재개하면 다시 계산합니다. 시작 대기는 0초부터 지정할 수 있으며 기존 60초 상한을 해제했습니다. 매우 긴 대기로 날짜 표현 범위를 넘으면 날짜 표시 범위 초과로 표시합니다.
