# AutoInput — 문서 자동 입력 v1.1.0

Windows x64 / C# Windows Forms. TXT·DOCX 내용을 클립보드 없이 키보드 이벤트로 한 글자씩 입력합니다. .NET과 Python을 별도로 설치할 필요가 없습니다.

## 설치 및 제거

`dist/AutoInput-Setup-1.1.0-x64.msi`를 더블 클릭합니다. 현재 사용자용으로 `%LOCALAPPDATA%/Programs/AutoInput`에 설치하며 시작 메뉴·바탕화면 바로가기를 만듭니다. Windows 설정 → 앱 → 설치된 앱 → AutoInput → 제거에서 삭제합니다. 설정·오류 로그·저장 작업은 제거 시 보존합니다. 이 데이터까지 삭제하려면 프로그램을 종료하고 `%LOCALAPPDATA%/AutoInput` 폴더를 직접 삭제합니다.

설치 없이 쓰려면 배포 ZIP의 `AutoInput.exe`를 실행합니다.

## 사용 방법

1. TXT / DOCX 선택 → 내용 확인·수정
2. 시작 대기 시간(초)과 글자 간격(ms) 설정
3. F8을 누른 뒤 대기 시간 안에 대상 입력창 클릭
4. 입력 중에는 대상 창을 유지

- **F8**: 처음부터 입력 시작
- **F10**: 일시정지 / 같은 위치에서 재개
- **F9 또는 Esc**: 중지
- **저장 위치에서 시작**: 중단한 위치에서 이어 입력

시작 대기는 0초부터 긴 시간까지 지정할 수 있습니다. 재개할 때도 지정된 대기 시간을 적용합니다. F8은 저장된 위치와 관계없이 처음부터 시작합니다. 대상 앱의 커서나 기존 내용은 자동 복원하지 않으므로 이어 입력 전 직접 맞추세요.

## v1.1.0 개선 사항

### 중단 위치 저장

문서 내용과 입력 위치를 사용자별 `work.json`에 저장하고 다음 실행 시 불러옵니다. 중지·일시정지·정상 종료 시 저장하며 입력 중에는 약 1초 간격으로 저장합니다. 강제 종료 시 마지막 약 1초 분량이 다시 입력될 수 있습니다. 입력 완료 시 저장 작업은 제거합니다. 미리보기 내용을 편집하면 저장 위치는 처음으로 돌아갑니다.

설정의 ‘중단 위치 자동 저장’을 끄면 디스크에 저장된 작업을 삭제합니다. 도움말 → 저장 작업 삭제에서도 지울 수 있습니다. 문서 내용은 이 PC에 일반 텍스트 JSON으로 저장되며 업데이트 확인 시 전송하지 않습니다.

### 진행률과 예상 시간

진행 막대, 백분율, 완료·전체·남은 글자 수를 표시합니다. 한글과 이모지는 각각 한 글자로 셉니다. 예정 시각은 설정된 글자 간격을 바탕으로 한 근사치입니다. 대상 앱의 실제 입력·저장 성공을 확인하는 기능은 아닙니다.

### 별도 설정 화면

좌측 상단 설정을 누르면 다크 모드, 자동 줄바꿈, 항상 위에 표시, 시작 시 최소화, 글자 크기, 대기·입력 간격, 작업 저장, 시작 시 업데이트 확인을 한 화면에서 변경합니다. 저장을 눌러야 적용되며 취소하면 변경하지 않습니다. 입력 중 설정이나 도움말을 열면 일시정지됩니다.

### 오류 기록

파일 읽기·저장·업데이트·입력 오류를 `%LOCALAPPDATA%/AutoInput/logs`에 날짜별로 기록합니다. 도움말 → 오류 로그 폴더 열기로 확인하세요. 정상 입력 본문은 오류 로그에 기록하지 않습니다.

### 업데이트 확인

도움말 → 업데이트 확인에서 `piuswjk628/autotext-auto_writer`의 공개된 최신 정식 GitHub Release를 확인합니다. 새 버전이 있으면 배포 페이지를 열 수 있습니다. 다운로드·설치는 직접 진행합니다. 자동 확인은 설정에서 켤 수 있으며 기본값은 꺼짐입니다. Release 태그는 `v1.1.0`, `v1.2.0` 같은 형식을 사용하세요. 공개 Release가 없거나 인터넷 연결이 실패하면 안내합니다.

## 참고 사항

줄바꿈은 Enter, 탭은 Tab 키로 전송합니다. 채팅창에서는 Enter로 메시지가 전송될 수 있으므로 메모장에서 먼저 확인하세요. DOCX는 본문과 표를 읽으며 서식·그림·머리글은 포함하지 않습니다. 관리자 권한의 대상 앱이나 유니코드 이벤트를 받지 않는 앱에서는 입력되지 않을 수 있습니다.

## Visual Studio / 빌드

.NET 10을 지원하는 Visual Studio와 .NET 데스크톱 개발 워크로드가 필요합니다. `AutoInput.sln`을 열고 F5로 실행합니다. Release 게시에는 `Windows` 프로필을 사용합니다.

```powershell
dotnet publish AutoInput.csproj -p:PublishProfile=Windows
```

설치 파일 재생성:

```powershell
powershell -ExecutionPolicy Bypass -File Installer/Build-Installer.ps1
```

스크립트는 WiX 5.0.2를 프로젝트 `tools` 폴더에 설치해 MSI를 만듭니다. 버전 변경 시 `AutoInput.csproj`, `UpdateService.CurrentVersion`, `Installer/Package.wxs`와 설치 파일명을 함께 갱신합니다. 설치 패키지의 UpgradeCode는 다음 업데이트에서도 유지하세요.

검사:

```powershell
dotnet run --project ../AutoInputChecks/AutoInputChecks.csproj
```
